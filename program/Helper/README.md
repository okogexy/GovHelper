# Veyron • GovHelper

Новая независимая версия помощника для Majestic RP. Приложение работает с локальными базами серверов, не требует лицензионного ключа для офлайн-функций и хранит пользовательские настройки отдельно от старого клиента.

## Команды

- `npm run dev` — режим разработки.
- `npm test` — тесты слоя данных.
- `npm run build` — сборка интерфейса.
- `npm run dist` — portable Windows `.exe` в папке `release`.

## Авторизация

Программа использует аккаунт сайта. По умолчанию API доступен по `http://127.0.0.1:8000/api/v1/program`; для опубликованного сайта задайте переменную `GOVHELPER_API_URL=https://ваш-домен/api/v1/program`.

## Данные

Исходные базы находятся в `resources/databases`. Пользовательские настройки, избранное и заметки сохраняются в стандартной папке Electron `userData`. Импорт старых данных выполняется явно из настроек.
